# Схема графа

Модель данных. Цель — чтобы скелет можно было собрать в интерактивный граф
(как `master.html` у `wcs-skills-map`), а пока — чтобы тексты веток были
единообразны.

## Типы узлов

### skill (узел-навык)
Единица того, что осваивают.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | строка | стабильный slug, напр. `weight-transfer` |
| `label` | строка | человекочитаемое имя, напр. «перенос веса» |
| `branch` | enum | `техника` · `фразы` · `слова` · `разговор` |
| `level` | int | сложность узла внутри ветки (1=базовый…). **Не зрелость владения** |
| `voices` | список | подмножество `{я, коннекшен, музыка}` |
| `desc` | текст | что это и зачем (одним-двумя предложениями) |
| `needs` | список id | какие узлы нужны для этого (рёбра «нужно для») |
| `unlocks` | список id вех | какие вехи открывает |

### milestone (узел-веха)
Celebratable достижение.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | строка | slug, напр. `first-call-and-response` |
| `label` | строка | «впервые задал вопрос и услышал ответ» |
| `celebrate` | текст | как это звучит как праздник/признание |
| `fed_by` | список id | какие узлы-навыки к ней ведут |
| `expression` | текст | как именно связана с самовыражением (звездой) |
| `context` | enum? | где случается: `класс` · `вечеринка` · `контест` · `сцена` (опц.) |

## Типы рёбер

- **нужно для** (`needs`): skill → skill. Чаще всего **межветочное по уровню**
  (фраза-N ← техника-N), бывает внутриветочное (вариация ← фраза).
- **ведёт к вехе** (`unlocks` / `fed_by`): skill → milestone.

Голоса (`я / коннекшен / музыка`) — **не узлы и не рёбра**, а тег на узле.
Звезда (самовыражение) — единый «магнит» наверху, на неё указывают вехи; в
данных её можно не материализовать.

## Уровни

Рабочие ярлыки сложности внутри ветки: **Базовый · Средний · Продвинутый**
(уточнятся числом уровней после рисёрча). Межветочные связи выравниваются по
этим уровням.

> Зрелость владения узлом (знание → умение → навык) — отдельное измерение,
> сейчас **отложено** (см. `00-foundation.md` §7). В схему добавим позже полем
> `maturity`, не ломая остального.

## Эскиз JSON (для будущей сборки)

```json
{
  "skills": [
    {
      "id": "weight-transfer",
      "label": "перенос веса",
      "branch": "техника",
      "level": 1,
      "voices": ["я"],
      "desc": "чистый перенос центра тяжести на каждый счёт",
      "needs": [],
      "unlocks": ["partner-understands"]
    }
  ],
  "milestones": [
    {
      "id": "partner-understands",
      "label": "партнёр понимает тебя без усилий",
      "celebrate": "вас понимают — вы двигаетесь как одно",
      "fed_by": ["weight-transfer", "even-tone"],
      "expression": "чистая «речь»: основа, без которой нечего сказать",
      "context": "класс"
    }
  ]
}
```
