# Четыре ветки — узлы по уровням

> Заземлено на существующий рисёрч (см. `90-research-notes.md`). Формат узла —
> `01-schema.md`. Ветки растут **параллельно**; межветочная связь — «по уровню».
>
> Уровни: **Б** базовый (≈ L1) · **С** средний (≈ L2) · **П** продвинутый (≈ L3+).
> Голоса: **я** · **кон** (коннекшен/партнёр) · **муз** (музыка).
> Источник: **McK** McKeever · **rep** рисёрч-репорт/canon · **map** карта 14 веток.

---

## Ветка 1. Техника (произношение)

Без неё «тебя не понимают». Сквозь неё проходят все три голоса. Голос «я» удобно
вести по 8-шаговой лестнице Swing Literacy:
`pitch → posture → footwork → timing → pulse → turning → contrabody → arm styling`.

| Ур. | Узел | Голоса | Нужно для | Ист. |
|-----|------|--------|-----------|------|
| Б | базовый ритм (walk-walk-triple-triple; heavy-light-light) | я, муз | — | McK, rep |
| Б | слышу бит (down/up, bass/snare) | муз | — | McK |
| Б | осанка и питч (posture, pitch) | я | — | rep |
| Б | базовый фрейм | кон | осанка | McK |
| Б | хэндхолд, связь рука-тело | кон | фрейм | McK |
| Б | слот / track | я, кон | — | McK, map |
| Б | send & catch (веду назад — ловлю) | кон | фрейм | McK |
| Б | anchor — положение тела / эластичный стретч | кон, я | send & catch | McK, rep |
| Б | базовые compression & stretch (A-frame / V-frame) | кон | anchor | McK |
| С | перенос веса, critical timing (strike-transfer-complete-prepare) | я | базовый ритм | McK |
| С | rolling count | муз, я | critical timing | rep, McK |

## Ветка 2. Фразы (паттерны-разговорник)

Готовые паттерны целиком. **Правило связи: фраза уровня N требует Техники того же
уровня.** Whip — точка перегиба (8-счёт + закрытая позиция), НИКОГДА не первый урок.

| Ур. | Узел | Голоса | Нужно для | Ист. |
|-----|------|--------|-----------|------|
| Б | Sugar Push / Push Break | кон | anchor, send & catch | McK, rep |
| Б | Left Side Pass | кон | слот | McK, rep |
| Б | Underarm Turn / Right Side Pass | кон | Left Side Pass | McK, rep |
| Б | Starter Step / Throwout | кон | базовый ритм | rep, McK |
| С | Sugar Tuck (intro preps) | кон | anchor | McK |
| С | Passing Tuck | кон | Sugar Tuck | McK |
| С | Turning Basic | я, кон | turning technique | McK |
| С | Free Spin / Inside Turn | я | turning technique | McK |
| С | First Whip (8-count, closed) | кон | фрейм + compression & stretch | McK, rep |
| С | Basket Whip | кон | First Whip | McK |
| П | whip-вариации (inside / outside / open / behind-the-back) | кон | First Whip | McK |
| П | Reverse Whip | кон | whip-вариации | McK |
| П | Hammerlock + exits | кон | whip-вариации | McK |
| П | длинные связки, смены направления | кон | — | rep |

## Ветка 4. Разговор (самовыражение) — сердце

Где цветёт звезда. Собирает все три голоса. Lead/follow = «send and catch»;
follow — primary mover. Styling из центра — роль фолловера; вести стиль партнёра нельзя.

| Ур. | Узел | Голоса | Нужно для | Ист. |
|-----|------|--------|-----------|------|
| Б | вопрос — ответ (приглашение / отклик) | кон | фразы-Б | McK, map |
| Б | присутствие, не паникую от ошибки | я | — | rep |
| Б | базовая музыкальность (down/up, pulse с музыкой) | муз | слышу бит | McK |
| Б | маленькая игривость | я, кон | — | map |
| С | активное слушание (непрерывный двусторонний коннекшен) | кон | elasticity | McK, rep |
| С | интонирование (личный стайлинг из центра) | я | contrabody + arm styling | rep, map |
| С | паузы (оставить место) | кон, муз | базовая музыкальность | rep |
| С | фразировка (8/32, minor / major phrases) | муз | базовая музыкальность | McK |
| С | подводка к теме (прелид / преп) | кон | preps (слова-С) | McK |
| С | перехват — интро (голос фолловера) | кон | слова-С | rep, map |
| С | акценты — базовые хиты | муз, кон | фразировка | McK |

| П | смена темы / продвинутый перехват | кон | слова-П | map |
