# Карта развития танцора WCS — v2 (граф)

Свежая пересборка модели развития танцора весткоста **с нуля**, как
направленный граф. Заменяет линейный черновик
[`../WCS-DANCER-DEVELOPMENT-MAP-v1.md`](../WCS-DANCER-DEVELOPMENT-MAP-v1.md)
(оси × ступени) на граф из параллельных веток, узлов-навыков, связей и вех.

## Полярная звезда

**Самовыражение через танец в паре.** Танец в паре — это разговор без слов;
развитие — это путь к тому, чтобы всё свободнее выражать себя в этом разговоре.
Звезда видна с первого занятия: даже новичок понимает, *зачем* мы делаем то,
что делаем.

## Что где лежит

| Файл | Содержание |
|------|------------|
| `graph.txt` | **Источник правды** данных графа (компактный, по строке на узел). Правим здесь. |
| `build.mjs` | Сборщик: парсит `graph.txt`, валидирует, генерирует `graph-data.js`, вшивает данные в html |
| `graph-data.js` | **Генерируется** build.mjs — не редактировать вручную (нужен только как офлайн-fallback) |
| `gh-sync.js` | Общий рантайм страниц: на https подтягивает свежие `graph.txt`/`blocks.txt` и сохраняет правки обратно в GitHub по токену (см. ниже) |
| `index.html` | Интерактив: **матрица/роадмап** «ветки × (уровни / блоки)»; перетаскивание карточек между блоками + «💾 Сохранить в GitHub» (`blocks.txt`) |
| `network.html` | Интерактив: **сеть** (Cytoscape.js + dagre, авто-раскладка; нужен интернет для CDN) |
| `editor.html` | Интерактив: **редактор связей** (добавить/удалить ребро) + «💾 Сохранить в GitHub» (`graph.txt`) |
| `blocks.txt` | **Источник** группировки по 3-мес. блокам (правим перемещением id между b*) |
| `synonyms.md` | Справочник имён фигур: синонимы и «ложные друзья» |
| `00-foundation.md` | Зафиксированные решения, идентичность модели, что отвергнуто |
| `01-schema.md` | Схема графа: типы узлов, рёбер, теги, уровни, вехи |
| `02-branches.md` | Четыре ветки и их узлы по уровням (читаемый дубль данных) |
| `03-milestones.md` | Вехи, которые можно праздновать |
| `90-research-notes.md` | Заметки дип-рисёрча по программам студий и танцоров |

## Как править граф

Опубликовано: **https://akarakotov.github.io/wcs-map/dancer-graph/**
(матрица), `/network.html` (сеть), `/editor.html` (редактор связей).

### Онлайн (рекомендуется, без локальных файлов)

1. Открой опубликованную страницу.
2. Двигай карточки между блоками (матрица) или меняй связи (редактор).
3. Жми **«💾 Сохранить в GitHub»**. Первый раз страница попросит токен — см. ниже.
   Кнопка коммитит `blocks.txt` (матрица) или `graph.txt` (редактор) прямо в репо.
4. Через ~1 минуту (пересборка GitHub Pages) страница при перезагрузке читает свежие
   данные — отдельная сборка не нужна, страницы тянут `graph.txt`/`blocks.txt` на лету.

**Токен** (один раз, хранится только в твоём браузере): GitHub → Settings →
Developer settings → **Fine-grained tokens** → New token → Repository access:
только `akarakotov/wcs-map` → Permissions → **Contents: Read and write** → создать,
скопировать, вставить в окно при первом сохранении. Сбросить —
`localStorage.removeItem('wcs_gh_token')` в консоли браузера.

### Локально (запасной путь)

1. Открой `graph.txt`, добавь/измени строку узла или вехи (формат описан в шапке файла).
2. Прогони `node build.mjs` — он провалидирует (висячие ссылки, дубли, неверные
   ветки/уровни/голоса, инверсии уровня, избыточные связи) и вшьёт данные в html
   (вшитый снимок — это офлайн-fallback для открытия по `file://`).
3. Запушь изменённые файлы в `akarakotov/wcs-map` (папка `dancer-graph/`).

> `02-branches.md` / `03-milestones.md` — человекочитаемое зеркало; при расхождении
> с `graph.txt` правда за `graph.txt`.

## Статус

В разработке. Совместная пошаговая проработка (web → локально). Скелет веток
строится **на базе дип-рисёрча** по учебным программам других студий и
известных преподавателей WCS. Шкала зрелости узла (знание→умение→навык)
сознательно отложена — сейчас в фокусе структура, ветки, связи и вехи.
