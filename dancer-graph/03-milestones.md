# Вехи, которые можно праздновать

> Заземлено на маркеры прогресса из рисёрча (см. `90-research-notes.md`). Веха —
> celebratable узел: чем питается → где случается → как связана со звездой
> (самовыражением). Источник: **McK** · **rep** · **map** (см. branches).

| Веха | Питается узлами | Контекст | Самовыражение | Ист. |
|------|------------------|----------|---------------|------|
| Тебя понимают без слов | anchor, связь, перенос веса | класс | чистая «речь» — основа, без которой нечего сказать | rep, McK |
| Первая музыкальная фраза (32 счёта) | 3 фразы-Б + anchor | класс | впервые «сказал» целое предложение под музыку | rep |
| Первый соц. танец с незнакомцем | фразы-Б, слот, присутствие | вечеринка | можешь сам поддержать разговор | rep |
| Первый вип | фрейм + compression/stretch + 8-счёт | класс | взял точку перегиба — открылся «закрытый» разговор | rep |
| Собрал базовый словарь (L1→L2) | starter, side passes, sugar push/tuck, passing tuck, free spin, whip | gate | язык собран — есть чем говорить | rep |
| Вставил свою первую вариацию | слова-Б | вечеринка | впервые сказал своё слово, не по заученному | map |
| Первая синкопа в ритм | синкопы-С + музыка | вечеринка | заиграл с ритмом, а не только с шагами | McK |
| Задал вопрос и услышал ответ | вопрос-ответ + активное слушание | вечеринка | первый настоящий диалог, а не монолог | map |
| Поймал акцент вместе с партнёром | акценты + связь + музыка | вечеринка | втроём (ты + партнёр + песня) совпали в моменте | McK |
| Первый перехват | перехват + слова-П | вечеринка | твой голос зазвучал на равных | map |
| Сделал песню «своей» | фразировка-П, интонирование, игра | соц / сцена | у тебя появился почерк | map, rep |
| Первый Jack & Jill | соц. уровень + присутствие | контест | вышел говорить «на людях» | McK |

## Заметки
- Вехи **не выстроены в одну линию** — они висят на разных ветках и уровнях;
  танцор берёт их в своём порядке (желание ведёт), модель лишь подсвечивает, что
  каждую питает.
- Контексты (класс / вечеринка / контест / сцена) — это *где* празднуют, а не
  отдельная ветка.
- Gate-вехи («собрал словарь L1→L2») удобны школе как мягкий ориентир перехода
  уровня (Mission City model), но подаются как достижение, не экзамен.
